## 答辩时大概率被问到的

准备好这 8 个问题的答案，都在这份代码里能找到依据：

1. **为什么选这个目标？** —— 不在 COCO 里 + 和战队任务相关。
2. **数据集怎么来的？多少张？每类多少？** —— 记住具体数字，别说"挺多的"。
3. **怎么划分 train/val/test 的？** —— 8:1:1，固定 seed，同一个场景的连续帧要放同一边，否则泄漏。
4. **为什么用 yolov8n 不用大的？** —— 数据量小，大模型过拟合；n 的推理速度满足实时。
5. **mAP 怎么算的？** —— IoU 阈值 0.5 下的 PR 曲线面积；mAP50-95 是 0.5~0.95 十档平均。
6. **误检怎么处理？** —— 负样本（空标签图）+ 调 conf 阈值 + 后处理面积/长宽比过滤。
7. **这个模型能上车吗？** —— 说清楚差距：没有跟踪、没有标定、没有和电控通信；下一步是 TensorRT + 卡尔曼。
8. **版本树里这几轮分别改了什么、为什么涨/跌？** —— 这是最能体现"你真的在迭代"的问题。
